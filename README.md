# 🎲 The Dice Game

A fun. Interactive two player Dice Game created using HTML, CSS and JavaScript. Roll the dice challenge the person and find out who wins.

## 🌐 Live Demo

**Play the game here:**

https://rizwan-bm.github.io/The-Dice-Game/

## ✨ Features

- 🎲 dice rolling

- 👥 Two player gameplay

- 🏆 Automatic winner announcement

- 🔄 Restart and play again

- 🎨 Simple and user friendly interface

- 📱 Responsive design

## 🛠️ Technologies Used

- **HTML5** – Website structure

- **CSS3** – Styling and layout

- **JavaScript** – Game logic and interactivity

## 🚀 How to Run Locally

1. Clone this repository:

```bash

git clone https://github.com/rizwan-bm/The-Dice-Game.git

```

2. Open the project folder in Visual Studio Code.

3. Open index html in your browser. Use the Live Server extension.

4. Start rolling the dice and enjoy the game!

## 🎮 How to Play

1. Open the demo.

2. Roll the dice for both players as per the game controls.

3. Check the dice results.

4. The player, with the result wins the round.

The exact rules depend on the games implementation.
